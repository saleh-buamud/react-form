# React Form Validation

A responsive form built with **React + TypeScript + Vite**.

This project was created as a practical exercise to learn React state management, controlled inputs, form validation, TypeScript, and reusable components.

## Features

* Personal information form
* Controlled form inputs
* Name validation
* Phone number validation
* Age validation
* Employment status selection
* Salary selection
* Form submission validation
* Success and error messages
* Reusable modal component
* TypeScript type safety
* Responsive design

## Technologies

* React
* TypeScript
* Vite
* CSS
* ESLint

## Form Validation

The form validates:

* Full name must contain more than 3 characters.
* Phone number must contain exactly 11 characters.
* Age must be between 10 and 100.
* Employment status must be selected.
* Salary must be selected.

The Submit button remains disabled until the required fields are completed.

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project:

```bash
cd react-form-validation
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.
